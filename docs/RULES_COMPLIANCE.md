
## SigmaHQ License Verification (M2)
We verified the current SigmaHQ license. The rules are released under the Detection Rule License (DRL) 1.1. While permissive for commercial and personal use, DRL 1.1 strictly mandates retaining author attribution in any alerts or messages generated by the rules. To avoid complex attribution tracking in Guardian's offline alerting pipeline, we opted not to import SigmaHQ content. Instead, we authored a small set of original, custom rules in a Sigma-inspired YAML format tailored to our `audit_events` schema.
